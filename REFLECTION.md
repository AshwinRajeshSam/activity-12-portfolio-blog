# Activity 12: Reflection on Prompt Engineering vs Hand-Coding

### 1. Which prompt produced the biggest improvement?
Prompt Refinement #1 (specifying exact project names, technologies, and verified GitHub repository URLs) produced the most substantial improvement. The initial output generated generic placeholder cards ("Project 1", "Project 2"). Once provided with specific project artifacts from Activities 5–8, the generated output transformed into an authentic, recruiter-ready engineering portfolio that directly reflects real coursework.

### 2. What is one thing the AI got wrong that had to be corrected?
The AI initially hallucinated generic external frameworks (such as React and Tailwind CDN scripts) despite the brief explicitly requesting vanilla HTML5, modern CSS, and lightweight JavaScript. This was corrected in refinement prompting by reinforcing zero-dependency constraints, resulting in a lightweight, lightning-fast static bundle suitable for GitHub Pages.

### 3. Key Takeaway on AI-Assisted Development
Directing an AI tool with a structured, multi-page content brief mirrors real-world product management. The quality and specificity of the brief directly dictate the utility of the output; clear constraints and concrete project references eliminate filler content.
